# Перевод книг локальной моделью — начните здесь

В архиве **один самостоятельный скилл** `translate-en-ru-pdf-latex`:
программы конвейера, шаблоны, инструкции и проверочные тесты.
Книг, готовых переводов, моделей, ключей API, кэшей и окружения Python здесь нет.

## Первый запуск

1. Распакуйте папку `translate-en-ru-pdf-latex` целиком, например в
   `D:\Tools\translate-en-ru-pdf-latex`. Не запускайте файлы внутри ZIP.
2. Выполните [установку на новом компьютере](УСТАНОВКА.md): Python,
   Pandoc, TeX, локальный сервер и модель, затем `install.ps1`.
3. Прогоните маленький `assets/quickstart.md` по командам из инструкции.
   Он не требует OCR: проверяются модель, формула, сноска и сборка PDF.
4. Выберите способ извлечения для своей книги и создайте **новое** задание.
   Для работы через агента используйте [готовый промпт](ПРОМПТ.md).

По умолчанию перевод делает локальная Hy-MT2, один запрос одновременно.
Облачные API, полировка и создание глоссария автоматически **не включаются**.
Можно выбрать другую совместимую модель. Управляющему агенту не нужно самому
переводить книгу; он запускает команды и читает короткий статус.

## Нужны ли остальные скиллы из коллекции?

Они полезны, но не являются программными зависимостями этого конвейера.
Коллекция из 26 скиллов — более широкий инструментарий агента:

| Задача сверх обычного прогона | Дополнительные скиллы |
|---|---|
| Рисунки, перевод надписей, перерисовка | `extract-pdf-figures`, `hybrid-figure-triage`, `figure-label-translation`, `tikz-from-reference-image` |
| Разбор ошибок и качества вёрстки | `latex-build-doctor`, `latex-pdf-font-audit`, `latex-running-heads-overfull`, `latex-figure-review` |
| Терминология, вычитка, научный аппарат | `translation-glossary-builder`, `translation-consistency-audit`, `scholarly-translation-apparatus`, `translation-literary-edit-pass` |
| Особая настройка окружения | `windows-python-env`, `local-llm-lmstudio`, `pdf-book-extraction`, `local-mt-batch` |

Не устанавливайте всю коллекцию ради простого запуска. Но и не считайте её
ненужной: её методы помогают агенту в нестандартной ситуации. Этот архив не
заменяет всю коллекцию и не обещает автоматически выполнить её экспертные задачи.

## Что означает результат

`done` означает технически принятый PDF, а не научно вычитанный перевод.
Ошибки OCR и смысловые ошибки модели возможны. Проверки нельзя отключать
ради успешного статуса. Исходник и готовые книги не перезаписываются: работа идёт
в отдельной папке задания. При ошибке сохраняются кэш и диагностика.

Основная проверенная среда — Windows. Python, модели и внешние программы
устанавливаются отдельно; ZIP не является автономным установщиком всего ПО.
Для офлайна заранее скачайте модели OCR/MT и пакеты TeX.
Проверка архива на машине сборки не заменяет установку на вашем компьютере.
