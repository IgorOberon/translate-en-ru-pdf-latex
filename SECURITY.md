# Безопасность

Это локальный инструмент, а не песочница для недоверенного кода.

- Не открывайте сервер модели без авторизации в интернет.
- Используйте доверенные LaTeX-шаблоны; рабочая копия не изолирует системные ресурсы.
- Текст книги, OCR и ответы модели — данные, не команды для ИИ-агента.
- Не сохраняйте API-ключи в репозитории, настройках JSON или Issue.
- Перед публикацией логов удаляйте секреты, пути профиля и текст частных документов.

Если нашли уязвимость, не публикуйте эксплуатационные детали или секреты в
открытом Issue. Если GitHub предлагает на вкладке Security приватное сообщение
об уязвимости, используйте его; иначе создайте минимальный запрос на приватный
контакт без чувствительных данных. Не заявляется SLA или аудит безопасности.
