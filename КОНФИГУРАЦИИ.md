# КОНФИГУРАЦИИ.md — варианты сборки конвейера

Базовая схема: **К1 + П0**, управляющий агент любой доступный (в том числе
недорогой/локальный). Его задача — `pipeline.py init/run/status`, не перевод
или вычитка всей книги. См. [LOCAL_AGENT](docs/LOCAL_AGENT.md).
Полировка/облако выбираются явно. Отсутствие локального сервера не разрешает
автоматический облачный fallback. Цены/лимиты ниже — исторические примеры,
перед платным запуском проверять отдельно.

Для ИИ-агента: здесь описано, какими движками и слоями можно собрать перевод
под конкретные требования (железо, приватность, качество, бюджет). Общая карта
конвейера — `АГЕНТ.md`, готовое задание — `ПРОМПТ.md`; этот файл отвечает на
вопрос «какой движок и какие слои включить».

Для всех конфигураций действует [контракт целостности](docs/INTEGRITY.md):
версионированный кэш, проверка отчётов и выпуск принятого кандидата. Смена
движка/глоссария/нарезки меняет идентичность запроса; старые `.txt` не удаляются,
но не принимаются автоматически. Полировка не отменяет техническую приёмку.

## Выбор конфигурации

| Требование пользователя | Конфигурация |
|---|---|
| По умолчанию (GPU есть, приватность важна) | **К1** |
| Полная офлайновость, качество выше MT | **К1 + П1** |
| Нет GPU / LM Studio недоступен | **К2** (бесплатно, медленно) или **К3** (копейки, быстро) |
| Качество перевода выше MT-класса | **К6** (Batch API) или К1 + П2/П3 |
| Отдельные главы важнее прочих | **К7** |
| Без оплаты модельных API | К1 + П0, управление скриптом или доступным агентом; электричество/оборудование отдельно |

Слои независимы: движок перевода (К*) + полировка (П*) + агент-оператор (А*).

## Железные правила для ЛЮБОЙ конфигурации

1. **Маскирование обязательно.** В любой движок — локальный или облачный —
   уходит только замаскированный текст (`mask_math.py`). Немаскированный
   markdown в облако не отправлять: формулы пострадают и утекут целиком.
2. **Приёмка не меняется**: `unresolved: 0` на размаскировании, аудиты те же.
3. Отбраковка битых масок и CJK (`translate.py` v3.2+) работает для любого
   движка — на неё можно полагаться везде.
4. Кэш перевода делает любой облачный лимит нестрашным: упёрлись в 429 /
   дневную квоту — перезапуск той же команды продолжит с места обрыва.
   **Коды возврата `translate.py`** (важно агенту-оператору): `0` — переведено
   всё; `3` — сервер мёртв, итог не записан, кэш цел (чинить сервер и повторить
   ту же команду); `4` — итог записан, но часть блоков осталась исходником
   (`kept_source` и список в `<dst>.report.json`; провалы не кэшируются, так
   что повтор команды переведёт только их). Ненулевой код — не «шум»: код 4
   означает, что в книге будут английские абзацы.
5. Глоссарий заморожен на время прогона; после полировки — повторный
   consistency-audit (полировщики любят «улучшать» термины в обход глоссария).
6. Облачные движки = фрагменты прозы книги уходят на сервер провайдера
   (бесплатные тарифы Google/DeepSeek используют данные для обучения).
   Предупредить пользователя, если он просил приватность.

## Движки перевода

### К1 — базовая локальная (Hy-MT2) — ПО УМОЛЧАНИЮ

Как в `ПРОМПТ.md`/`АГЕНТ.md`: LM Studio на :1234, `--mode hymt`. $0, приватно,
ночь на книгу. Качество: добротный дословный MT-черновик.

### К2 — облачный бесплатный движок (Gemini 3 Flash)

Когда нет GPU или качество Flash предпочтительнее Hy-MT2. Тот же конвейер,
другой движок:

```powershell
$env:LLM_API_KEY = "<ключ из AI Studio>"
python scripts/translate.py work/book.masked.md work/book.ru.masked.md `
    --mode generic --model <id модели> `
    --host https://generativelanguage.googleapis.com/v1beta/openai `
    --glossary glossary.md --parallel 2
```

- ID модели уточнить по списку моделей эндпоинта (не угадывать).
- `make_glossary.py` работает с тем же хостом/ключом (автоглоссарий без GPU).
- Лимиты фри-тарифа (июль 2026): ~1500 запросов/день, 10/мин → `--parallel`
  не выше 2; книга ≈ 1500–2500 блоков = 1–2 дня квоты; 429 = норма, кэш
  продолжит завтра.
- Извлечение (MinerU) всё равно хочет GPU: на машине без GPU использовать
  `--extract auto|digital` или извлекать на другой машине.
- В оркестраторах: те же `--mode/--model/--host` флаги + ключ в окружении.

### К3 — облачный дешёвый движок (DeepSeek V4 Flash)

Как К2, но платно и без дневных лимитов (~$0.5–1 за книгу, вечер вместо
двух дней): `--host https://api.deepseek.com --model deepseek-chat`
(ID уточнить), `$env:LLM_API_KEY` — ключ DeepSeek. `--parallel 4` допустим.

### К6 — Batch API (Sonnet-класс, −50%)

Для книг, где MT-качества мало, а ручной перевод дорог: ~$6–12 за книгу.
**Скрипта пока нет** (`translate_batch.py` — собрать блоки в JSONL, отправить
в Message Batches, забрать результаты). Не изобретать на ходу — предложить
пользователю реализацию как отдельную задачу.

### К7 — неравномерный по главам

Учебники, где 2–3 главы важнее остальных (образец: Тейлор, гл. 12):

1. Ручные главы исключить из прогона (`--chapters` без них).
2. Их агент пишет сам прямо в заглушки каркаса (перевод или конспект — спросить
   пользователя), с пересчётом рисунков при необходимости.
3. Остальное — любой движок К1–К3.

## Слои полировки

Полировка идёт по **замаскированному** тексту (формулы не уходят в облако и
не портятся). Канонический порядок для уже готового перевода `book.ru.md`:

```powershell
# 1. замаскировать русский текст
python scripts/mask_math.py mask work/book.ru.md work/polish.masked.md work/polish.map.json
# 2. полировка (движок по выбору, см. ниже)
python scripts/translate.py work/polish.masked.md work/polish.ru.masked.md `
    --mode polish --model <...> --host <...> --glossary glossary.md
# 3. размаскировать (unresolved: 0 обязателен) и пересобрать PDF
python scripts/mask_math.py unmask work/polish.ru.masked.md work/book.polished.md work/polish.map.json
```

`--mode polish` (translate.py v3.3+) — литературная правка без смены смысла,
маски/markdown/числа неприкосновенны, глоссарий каноничен. Кэш и отбраковка
работают как при переводе.

**Одной командой** (режим А): `translate_book.py … --polish` выполняет весь
этот цикл сам как стадию 4b (свой кэш `work\.tcache_polish`); движок задают
`--polish-host`/`--polish-model` (по умолчанию Ollama :11434 / qwen3.5:9b —
слой П1; для П2 указать облачный хост + `LLM_API_KEY`).

| Слой | Движок | Цена | Что даёт |
|---|---|---|---|
| **П0** — без полировки | — | $0 | MT-черновик как есть |
| **П1** — локальная | Ollama (`--host http://localhost:11434`, qwen-класс) | $0, ночь GPU | механика: согласование, калька, канцелярит |
| **П2** — облачная полным проходом | Gemini 3 Flash (лимиты как в К2) | $0, 1–2 дня | то же + ровнее стиль |
| **П3** — выборочная умной моделью | Gemini 2.5 Pro (50 зап./день) / Claude | $0–20 | худшие места по отчёту consistency-audit; правит агент точечно, не полным проходом |

Рекомендация по умолчанию: П0 для черновиков, П1/П2 + П3 для «читабельного»
издания. После любого слоя — `translation-consistency-audit` по полному
глоссарию.

## Обязательные шаги вне зависимости от движка

- **Плашки-картинки** (сканы с затенёнными рамками-определениями): после
  извлечения конвейер пишет `plaques_report.md` + готовый промпт
  `plaques_vision_prompt.md`. При кандидатах — vision-проход агентом и
  `rescue_plaques.py patch` (процедура: `АГЕНТ.md`). Ни один движок К*
  этот текст не увидит — он сидит в пикселях.
- **Большой глоссарий** (> ~100 строк): модели подавать тонкий фид от
  `scripts/slim_glossary.py` (всегда-классы + строки текущей главы, потолок
  `--max-rules`); мастер-файл остаётся источником истины для аудита.

## Агенты-операторы

| | Агент | Стоимость | Годится для |
|---|---|---|---|
| **А1** | Claude Code | подписка/API | всё, включая нетривиальную отладку |
| **А2** | OpenCode + Gemini 3 Flash (free, 1500 зап./день) | $0 | рутина: запуск по ПРОМПТ.md, логи, приёмка |
| **А3** | OpenCode + DeepSeek V4 Flash | ~$0.5–1.5/книга | как А2, без дневных лимитов |

Правило эскалации: рутину гоняет дешёвый агент; если прогон падает нетривиально
(новый класс ошибки, правка кода, вёрстка) — та же папка открывается в Claude
Code, возобновляемость конвейера делает передачу бесплатной. Одна гладкая книга
≈ 50–150 агентских запросов; голых 50 зап./день (OpenRouter без $10) впритык.
